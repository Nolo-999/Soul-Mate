# 记忆模块 · 初版实现与优化路线

> 状态：初版开发中（2026-08-26）
> 原则：初版先跑通全链路，本文档第二部分记录所有已识别的优化点，按期推进。

---

## 一、初版范围（本期落地）

### 1.1 架构

```
用户消息 ──→ POST /api/v1/memories/extract（异步，不阻塞聊天）
              → Ollama qwen2.5:7b 本地抽取候选记忆
                （Ollama 不可用 → 静默降级，本次不入库）
              → 敏感过滤（身份证/手机号/密码 正则拦截）
              → 简单去重（同内容归并）
              → SQLite memory_unit 表
下一轮对话 ──→ GET /api/v1/memories/recall?q=...
              → 关键词召回 + 置顶优先 + 时间衰减排序
              → ChatPage：侧栏「记得的事」+ AI 回复挂真实 memoRef
```

### 1.2 数据模型 `memory_unit`

| 字段 | 类型 | 说明 |
|---|---|---|
| id | INTEGER PK | 自增 |
| content | TEXT | 记忆内容（一句话） |
| category | TEXT | fact / preference / event / day / emotion |
| importance | INTEGER | 1~5 |
| pinned | INTEGER | 用户置顶 |
| archived | INTEGER | 归档（不再召回但保留） |
| forgotten | INTEGER | 遗忘开关（永不召回） |
| source_msg | TEXT | 来源消息摘录 |
| created_at / updated_at | DATETIME | 时间戳 |

### 1.3 API（前缀 /api/v1/memories）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/` | 列表（支持 status=all/active/archived/forgotten） |
| POST | `/` | 手动新增记忆 |
| PATCH | `/{id}` | 置顶/归档/遗忘/编辑 |
| DELETE | `/{id}` | 物理删除 |
| POST | `/extract` | 从一段对话文本提取记忆（Ollama） |
| GET | `/recall?q=` | 召回与查询相关的 Top-K 记忆 |

### 1.4 前端接入点

- **ChatPage 侧栏「🧠 记得的事」**：写死假数据 → 真实接口数据
- **AI 回复 memoRef**：随机假引用 → 每次回复前调 recall，命中才挂「💬 你上次说…」
- **新页面 `/memories` 记忆卡片墙**：分类筛选 + 置顶⭐ / 归档📦 / 遗忘🚫 / 删除🗑
- 提取时机：用户发送消息后 fire-and-forget，失败不影响聊天体验

## 二、优化路线（已识别，按期推进）

| # | 优化点 | 说明 | 优先级 |
|---|---|---|---|
| 1 | 语义检索 | 关键词召回太糙；接本地 embedding（bge-small-zh，CPU 可跑），"面试"能召回"求职"类记忆 | 高 |
| 2 | 矛盾覆盖 | 用户改口"我不吃辣了"→ 新记忆应覆盖旧偏好而非并存，避免 TA 精神分裂 | 高 |
| 3 | 引用节奏控制 | 每句都引用很烦人；低频+关键时机提起才有惊喜感（如间隔 N 轮 / 情绪匹配时） | 高 |
| 4 | 拟人化遗忘 | 时间衰减权重：小事渐淡、重要日子（生日/纪念日）永不淡忘 | 中 |
| 5 | 分类细化和重要性模型 | 四类打标 + LLM 重要性评分调优；置顶/高频提及加权 | 中 |
| 6 | 主客观分离 | 观点低置信可衰减，事实高置信永久——对齐技术方案 4.3.2 | 中 |
| 7 | 重要日子主动提醒 | 纪念日/生日当天 TA 主动送祝福（联动防冷落系统） | 中 |
| 8 | 记忆隐私强化 | 明文敏感信息绝不落库（初版正则，后续加 LLM 复核） | 中 |
| 9 | 向量库升级 | SQLite → Milvus/Chroma（对齐终态架构，迁移 MySQL） | 低 |
| 10 | 记忆回放/回忆册 | "我们的一周年"场景：按时间线回放共同记忆 | 低 |

## 三、验收标准（初版）

- [ ] 发送含个人信息的消息（如"我下周三面试"）→ 卡片墙出现对应记忆
- [ ] 之后聊到相关话题 → AI 回复挂真实「💬 还记得你说…」
- [ ] 卡片墙四操作（置顶/归档/遗忘/删除）全部生效且影响召回
- [ ] Ollama 未启动时聊天完全不受影响（静默降级）
